# Coursework Publication Checklist

Before changing this repository to **Public** on GitHub, verify:

- [ ] The course has finished or public sharing is otherwise permitted.
- [ ] The course/university rules do not prohibit publishing assessed solutions.
- [ ] No instructor-provided starter code is included unless its licence permits redistribution.
- [ ] No assignment prompt, rubric, hidden/public test suite, answer key, or copyrighted teaching material is included.
- [ ] No student ID, course login, API key, password, or private information is present.
- [ ] The README describes the project accurately as a university course project.

If you cannot confirm the publication policy, keep the GitHub repository **Private** until you can check with the course handbook, LMS, or teaching staff.
